这本书没有作者

本站是为几个具体的人建的：一位馆长负责上传，其余几位朋友负责翻阅。 下面是一份尽量诚实的交代——关于它是怎么被做出来的， 以及为什么「作者」那一栏至今空着。

郑重声明 / Statement

本站全部代码、样式、数据结构与文案，均由自然语言指令生成。作者一栏留空不是谦虚，是事实。

如果你在源码里发现了一处手工痕迹，欢迎指出——我们会认真考虑把它删掉。 若发现错别字，请将其视为本版次的防伪特征，并顺手告诉馆长；他会口头感谢你，然后不一定改。

致谢

本馆由「想法」与「落实」两部分构成，分别由以下单位提供。 排名按登场顺序，不分先后，不设奖杯，也不发证书。

  • 灵感 · 想法

    ChatGPT

    负责说出「我们做一个数字图书馆吧」这句危险发言，并在深夜冷静地提议「要不要加一点 3D」。 它提供了全部想象力的上限，以及一部分「听起来很酷、实现起来会加班」的方案。

  • 落实 · 具体实现

    DeepSeek Harness

    负责把想法翻译成文件、把文件翻译成能跑的网页：写 CSS、接 PDF.js、量触控目标、 检查 320px 屏幕下有没有横向溢出、给 20 份讲义排版并印刷成 PDF。 被要求「再跳脱一点」时也没有拒绝。一句话概括它的工作方式：不睡觉，且不抱怨。

  • 环境 · 底气

    macOS

    提供字体渲染、截图能力，以及一切「看起来还行」的错觉； 顺手提供了终端、Python，以及那些 HTML 插件之类的东西—— 我们并不完全清楚「HTML 插件」具体指什么，但态度上必须感谢。

  • 技术

    PDF.js

    让 PDF 在浏览器里翻页、缩放、全屏。开源，零成本，功劳很大。

  • 技术

    HTML · CSS · JavaScript

    三位老朋友。三十年了还在干同样的活，并被要求「做得像书一样」。

  • 技术

    Python · Chrome Headless

    一个负责本地预览，一个负责一次性印刷 20 本小册子，并拒绝自己退出。

  • 技术

    Pillow

    产出那张 7 KB 的纸张纹理。全站唯一的图片，也是全站最沉默的功臣。

  • 技术

    Git · GitHub Pages

    负责免费把这本书放到互联网上，让「馆藏」这两个字不至于太寒酸。

  • 特邀

    馆长与朋友们

    馆长是本站唯一的人类贡献者：找资料、传资料、并坚称「这本去年考过」。 朋友们则是把它真正用起来的人——本站可以没有任何人写，但不能没有你们看。

说点正经的

上面的夸张都是真的，但最后一件事需要认真说：这个网站不替你学习。 它只做三件事——让你更快找到资料、当场翻开、需要时带走。

真正把讲义看完、把题做完、把东西记住的人，是你。 所以这份致谢的最后一栏，写的是馆长和你们的名字，而不是某个模型的版本号。
